✨ HOW IT WORKS IN 2 MINUTES

In your component:

  BEFORE (Hard-coded text):
  ┌─────────────────────────────┐
  │ export function MyComponent |
  │   return <h1>My Title</h1>  │
  └─────────────────────────────┘

  AFTER (Using translations):
  ┌────────────────────────────────────────────────┐
  │ 'use client';                                  │
  │                                                │
  │ import { useLanguage } from                    │
  │   '@/contexts/LanguageContext';               │
  │                                                │
  │ export function MyComponent() {                │
  │   const { t } = useLanguage();                 │
  │   return <h1>{t('page.title')}</h1>           │
  │ }                                              │
  └────────────────────────────────────────────────┘

That's it! When user clicks language switcher, text changes instantly.

📚 QUICK REFERENCE

"How do I..."

Add a new translation?
  → Edit public/locales/en.json
  → Run: npm run translate
  → Done!

Use translations in a component?
  → Import useLanguage
  → Call: const { t } = useLanguage()
  → Use: {t('key.name')}

Style Khmer text differently?
  → Check language: const { language } = useLanguage()
  → Apply class: language === 'km' ? 'font-battambang' : ''

Switch language programmatically?
  → Call: setLanguage('km')
